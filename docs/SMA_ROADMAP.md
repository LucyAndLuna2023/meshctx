# SMA — Small Model Amplification 小模型放大器 (产品路线 v7 方向)

> 用户定稿方向 (2026-09-22): 开源弱模型 + meshctx ≈ 强模型效果;
> 本地预处理省 token; 本地小模型处理大任务。
> 本文档回答三问: 能不能 / 有没有地基 / 怎么做。

## 0. 一句话答案

**能, 但限定在"结构化、可验证、有工具支撑"的任务域** — 这恰好是 Agent 任务的
主体。meshctx 已有的记忆精选注入已被自家 LongMemEval 实证: 同 16KB 预算下
增强注入 EM 41.7% vs 暴力截断 25.0% (**1.7 倍**) — 弱模型最缺的"上下文利用率"
正是 meshctx 的强项。缺的是三件: 级联路由 / 输出验证器 / 轨迹检索。

## 1. 弱模型变强的五条技术路径 × meshctx 现状

| 路径 | 原理 | meshctx 现状 |
|---|---|---|
| **上下文工程** | 精选注入替代暴力塞入; 结构化 prompt | ✅ 已有且实证 (记忆检索注入, v3.131.15 持久化) |
| **级联路由 cascade** | 简单任务→本地小模型, 复杂→云旗舰, 不确定→先小后大升级 | ❌ **缺** (123+ 模型可路由但无自动分级) — Phase 1 |
| **输出验证+自修复** | schema/可执行性/引用存在性校验, 失败带错误重试→升级 | ❌ **缺** — Phase 2 |
| **过程记忆 (轨迹检索)** | 检索历史成功轨迹让弱模型模仿强模型解法 | ◐ self_evolution 洞见注入是雏形, 缺轨迹级 — Phase 3 |
| **本地预处理** | 文档切片/摘要/嵌入全本地, 云端只收压缩相关上下文 | ◐ Ollama 集成+本地记忆落盘已有, 缺管线 — Phase 4 |
| (辅助) 自一致投票 | 小模型多次采样取多数, 成本仍远低于大模型 | ❌ Phase 2 顺带 |

## 2. 四阶段路线

### Phase 1 — 级联路由器 cascade router (1-2 周)
- 任务分级 L0/L1/L2: 规则引擎 + 本地小模型分类器双通道
  - L0 本地 (Ollama qwen3:0.6b/4b): 摘要/分类/格式化/改写/简单问答
  - L1 云中档 (deepseek-flash 等): 常规对话/代码
  - L2 旗舰 (opus/gpt 级): 复杂推理/架构设计
- 升级触发: 低置信度 / 工具循环失败 ≥N / schema 校验失败 / 用户显式
- token 计量看板: 每任务 L0/L1/L2 消耗与节省额
- 守门: 分级准确率抽检 ≥90%; 升级回放测试

### Phase 2 — 验证器 + 自修复 + 投票 (2-4 周)
- 验证器: 代码可执行 (沙箱)/JSON 可解析/引用文件存在/事实断言检索核对
- 失败链: 同模型带错误反馈重试 ×2 → 升级 L1/L2
- 自一致: L0 任务跑 3-5 采样取多数 (成本仍为大模型 1/20)
- 守门: 验证器误杀率 <5%; 端到端可靠性对比 (弱+meshctx vs 裸强模型)

### Phase 3 — 过程记忆: 轨迹检索 (4-8 周)
- 成功任务轨迹落盘: 任务→工具序列→中间输出→用户反馈 (含失败轨迹的"避坑"标记)
- 新任务检索 top-k 相似轨迹注入 (弱模型模仿强模型历史解法)
- 与 L2-L3 记忆巩固打通: 轨迹蒸馏为可复用技能卡
- 守门: 轨迹注入前后任务成功率对比 (目标: L0 模型 +20pp)

### Phase 4 — 本地预处理管线 (8-12 周)
- 文档→本地小模型切片/摘要/要点提取 (零 API token)
- 本地 embedding (Ollama nomic-embed) + 检索
- 云端只接收"压缩后的相关上下文" (预期节省 60-80% token)

## 3. 评测纪律 (审计文化沿用)

- 主基准: LongMemEval 口径 (已有 v7 方法论) + 新增 SMA-TaskSet (20 个分级任务)
- 对照组: 裸小模型 / 裸大模型 / 小模型+meshctx 三线
- 声称纪律: IS/OOS 必标; 多种子≥3; 未验证不称"突破" (002quant 制度)
- 产出: 公开 benchmark 报告 = 市场卖点 (与"断网记忆自证"同族, 实证营销)

## 4. 战略对齐

- 弱模型路线 = "本地预处理省 token + 离线干活"的产品化 → 与"fully local,
  fully offline"定位互锁
- 大厂不做的结构性原因: 云厂收入依赖大模型调用费, 省 token 与其商业模式冲突
- 变现: personal 免费 (L0 本地) / team 加级联策略配置 / enterprise 加私有模型治理
