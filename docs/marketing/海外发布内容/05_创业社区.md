## Indie Hackers — 产品故事（P0）

**发布入口**: https://www.indiehackers.com/post (用产品页面 + 发帖)

**帖子标题**: `Solo dev, 6 years, 250k lines: building an AI agent that evolves its own brain settings`

**正文**:
```
### The story
I spent 20 years in enterprise IT (Microsoft, Siemens) before starting this. Six years ago I asked a dumb question: why does every AI agent forget what I told it last week?

So I started building. Six years later it's 250,000+ lines of Python — an AI agent platform with 17 simulated brain regions, sparse distributed memory, and a genetic algorithm that evolves its own parameters.

### The product
MeshCtx is a desktop AI agent for Windows/macOS/Linux:
- 17 brain regions (PFC = working memory, hippocampus = memory replay, amygdala = salience...)
- SDM memory: O(2^1000) address space
- Evolution engine: API-controlled evolve/feedback (auto loop on roadmap)
- GenomicOptimizer: genetic algorithm tunes temperature/top_p/prompt style automatically
- 5-model swarm consensus for code review
- 10 languages including Arabic RTL

### The business model (anti-VC)
- Individuals: free forever (not a freemium trick — a bet)
- Team/Enterprise: in active development → waitlist (no price promises until shipped)
- Open Core AGPLv3: framework fully open source

Why free forever? Because memory + evolution win the long game. The moat isn't pricing, it's the 6 years of cross-disciplinary engineering (neuroscience × AI × systems).

### Numbers so far
- 250k+ lines Python, zero external deps for core engine
- v3.115.27: Windows installer (67.6MB) with 245+ hidden imports solved, 10 languages verified in CI
- 341/342 tests passing
- [add: GitHub stars count / downloads if any]

### What I'm looking for
- Feedback on the evolution engine approach
- First 100 power users
- Contributors for the plugin ecosystem (MCP protocol native)

Site: meshctx.com · GitHub: github.com/LucyAndLuna2023/meshctx

Ask me anything about solo-dev lifecycle, full-brain emulation, or the genetic optimizer.
```

**IH 要点**:
- IH 用户吃真实故事 + 数字，不吃营销
- 发帖后 24h 内回复所有评论（IH 算法看互动）
