## Discord — 官方社区承接（P1）

**目标**: 建官方 Discord，承接 HN/Reddit/PH 来的用户，形成留存闭环。

### 频道结构建议
```
# welcome (规则 + 自我介绍模板)
# announcements (版本发布 / 进化引擎里程碑)
# getting-started (安装 + 首次配置问答)
# show-and-tell (用户晒作品)
# ai-discussion (AI agent 技术讨论)
# plugin-requests (插件需求收集)
# contributions (贡献者协作 / good-first-issue)
# feedback (产品反馈)
```

### 首条公告（welcome 置顶）
```
👋 Welcome to the MeshCtx community!

MeshCtx is a full-brain-emulation AI agent platform — 17 brain regions, sparse distributed memory, and a genetic-algorithm tuning engine driven via API (evolve/feedback; roadmap: auto-trigger).

🆓 Free for individuals · 🧬 Open core (AGPLv3)

Get started:
1. Download: https://meshctx.com
2. Source: https://github.com/LucyAndLuna2023/meshctx
3. Ask anything in #getting-started

Rules: be kind, no spam, English/中文 both welcome.

The founder is a solo dev who's been at this for 6 years — questions and brutal feedback are both appreciated. 🙏
```

### Discord 运营要点
- 前 30 天创始人亲自回复每条消息
- 每周发 1 次 "Weekly evolution report"（GenomicOptimizer 进化数据 / 新 commit）
- 用 Discord 的 Community 功能（Server Guide + Rules screen）

## Facebook — 开发者/AI 群组渗透（P2）

> FB 群组比 FB 主页有效。**不要建主页硬推，进群组做价值输出。**

### 目标群组类型
- AI/LLM 开发者群组（如 "AI Developers", "LLM & GPT Developers"）
- Open Source 爱好者群组
- 独立开发者/创业群组

### 群组帖子模板（进群先观察 1 周再发）
```
Hi everyone — I'm a solo dev who spent 6 years building an AI agent platform with a neuroscience-inspired architecture: 17 simulated brain regions (prefrontal cortex, hippocampus, amygdala, default mode network...) and a genetic algorithm that auto-tunes its own parameters.

I wrote a deep dive on the SDM memory implementation here: [Dev.to link]
Open source: github.com/LucyAndLuna2023/meshctx

Happy to answer questions about full-brain emulation, genetic optimization, or the 6-year solo journey. Not here to sell — genuinely curious what builders think. 🤝
```

### FB 主页（最低配置）
- 简介: `Full-brain-emulation AI agent · 17 brain regions · self-adaptive · free for individuals · open core`
- 封面: 架构图
- 每周 1 条更新（引用 X 内容）
