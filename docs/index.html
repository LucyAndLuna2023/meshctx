Why MeshCtx?

Hierarchical Memory

4-tier memory system (L0-L4) modeled after human cognition. FSRS-powered spaced repetition schedules every review at the edge of forgetting — important info persists, trivia naturally decays, and every recall strengthens memory stability. A 3-layer schema pipeline (episodic→semantic→core) consolidates scattered events into reusable knowledge, and epigenetic-style context markers rank memories by what matters for the current conversation — not just what's globally important. Sleep-phase offline consolidation & ARCHIVAL pruning (recoverable) prune trivia — LongMemEval 48Q (oracle subset) EM 52-54% / judge 83.3%.

About MeshCtx
