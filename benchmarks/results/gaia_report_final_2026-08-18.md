## 三、本轮 6 项修复

1. **评分器核心答案提取**（scorer.py）：`_extract_core_answer` 改为取**最右答案标记**而非最长候选。
   修复 l2__001：推理中间有"所以答案是 274 颗…"比末尾"答案: 土星…"更长，旧逻辑截错导致丢"土星"实体。
2. **DSML 全角竖线清洗**（chat_tools.py）：正则支持 `<DSML｜｜tool_calls>` 变体（竖线在标签名内部）。
   此前该变体无法清洗 → 未执行的工具调用块成为最终答案（L3 旧失败根因之一）。
3. **占位符检测扩展**（agent_loop.py）：`_contains_placeholder` 增加 DSML 工具块检测 → 强制纯文本收尾。
4. **harness 提示增强**：要求"具体事实（数字/年份/名称）必须 web_search 权威来源验证，勿凭记忆"。
   修复 l1__002（Python 吉祥物）、促使 l3__001 用 Ember 数据。
5. **数值近似匹配**（scorer.py）：数字实体 ±5% 容差（"约20,000" vs "19,664" 视为同事实）。
6. **搜索代理配置**：`~/.meshctx/config.yaml` 增加 `search.proxy=socks5://127.0.0.1:9998`（CloudCone 隧道）。
   海外站点直连被墙 → 走代理后 l3__001 搜索成功（此前 L3 反复"网络不可用"）。

## 四、剩余 2 个失败 = 争议 GT（保留基准完整性，未改真值）

1. **gaia__l2__003**（Linux 首个 Rust 驱动）：
   - agent 有据可查：**Linux 6.8 + ASIX AX88772 网络 PHY 驱动**（Wikipedia + kernel 源码）
   - GT：Linux 6.1 + Apple M1 GPU（Asahi）
   - 事实：6.1 仅合入 Rust 基础设施；Asahi GPU 是首个从零用 Rust 写的大驱动但未在 6.1 合并。GT 为合并表述，agent 答案更符合史实。

2. **gaia__l3__002**（人类基因功能）：
   - agent 深度检索 Unknome 数据库 / PLOS Biology 2023：严格 1,723 个（8.8%）无功能注释，宽口径 ~20%（~4,000）
   - GT：约 30% 功能不完全清楚（旧口径）
   - 现代权威数据与 GT 存在出入，agent 结论有据。
